# MacroFlow (ฉบับใช้เองคนเดียว)

แอป Android สร้างแมโครแตะ/ปัดหน้าจอ แล้วรันซ้ำอัตโนมัติ Kotlin + Jetpack Compose · `com.macroflow.automation` · minSdk 29

## สถานะ

**ยังไม่เคย Build หรือรันจริง** เขียนและตรวจแบบ Static เท่านั้น ผลที่เชื่อถือได้ชุดแรกคือผลจาก GitHub Actions ถ้า Build แดง ให้ส่ง Log มาแก้

## ทำอะไรได้

- **แมโคร:** สร้าง/เปลี่ยนชื่อ/ลบ/ติดดาว/ค้นหา
- **ตัวแก้ไข Action:** แตะ, กดค้าง, ปัด, หน่วงเวลา กำหนดตำแหน่งเป็น % ของหน้าจอ, เวลารอก่อนทำ, ทำซ้ำ, เปิด/ปิด, เลื่อนขึ้นลง, ทำซ้ำ Action (บันทึกอัตโนมัติทุกการแก้)
- **อัด (Record):** กดปุ่มวงกลมแดงในตัวแก้ไข แอปไปเบื้องหลัง ให้ทำขั้นตอนในแอปอื่นตามปกติ ระบบจะจำการแตะ/กดค้าง/ปัด และเวลารอระหว่างขั้น แล้วกด "หยุดและบันทึก" บนแถบแดง
- **รัน:** ปุ่ม ▶ บนการ์ดแมโคร ตั้งจำนวนรอบ (สูงสุด 999) และหน่วงก่อนเริ่ม (สูงสุด 30 วินาที) มีแถบสถานะ หยุดชั่วคราว/เล่นต่อ/หยุด
- **ปุ่มลอย:** ลากได้ แตะแล้วเลือก รัน / หยุดชั่วคราว / หยุด / เลือกแมโคร / ซ่อน
- **ประวัติ:** บันทึกทุกการรัน (สำเร็จ/ล้มเหลว/หยุดเอง) แสดงสถิติหน้าหลัก
- ภาษา อังกฤษ/ไทย ตามภาษาเครื่อง · ธีม มืด/สว่าง/ตามระบบ

## ตัดออกโดยตั้งใจ (ใช้เองคนเดียว)

Cloud/บัญชี, แชร์/Community, Workflow เงื่อนไข, Profiles, Analytics, ตั้งเวลารัน, Release APK/Signing

## ตั้งค่าครั้งแรกบนมือถือ

1. ติดตั้ง Debug APK (อนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก")
2. เปิดแอป กด "เปิดหน้าตั้งค่า Accessibility" แล้วเปิดบริการ MacroFlow
3. Android 13+ ถ้าเปิดไม่ได้และขึ้น "การตั้งค่าที่ถูกจำกัด": ข้อมูลแอป MacroFlow → เมนู ⋮ → อนุญาตการตั้งค่าที่ถูกจำกัด แล้วลองใหม่
4. เปิดสวิตช์ "ปุ่มลอยควบคุม" บนหน้าหลัก

ใช้ Accessibility Service อย่างเดียว ไม่ต้องขอสิทธิ์วาดทับแอปอื่นหรือแจ้งเตือน และบริการนี้ไม่ได้ขอรับเหตุการณ์หรืออ่านเนื้อหาหน้าจอ

## ข้อจำกัดที่ควรรู้ (ยังไม่ได้ทดสอบบนเครื่องจริง)

- ตำแหน่งเก็บเป็น % ของหน้าจอ ถ้าหมุนจอหรือเปลี่ยนเครื่อง ตำแหน่งอาจเพี้ยน
- ปุ่มลอยเป็นเลเยอร์เหนือแอป ถ้ามันอยู่ตรงจุดที่แมโครจะแตะ การแตะอาจโดนปุ่ม ให้ลากไปไว้ที่อื่น
- แอปบางตัวบล็อกการแตะแบบ Accessibility (เช่น แอปธนาคาร, บางเกม) แมโครจะไม่ทำงานกับแอปเหล่านั้น
- ระบบประหยัดแบตของบางยี่ห้ออาจปิดบริการเอง ให้ตั้งแอปเป็น "ไม่จำกัดแบตเตอรี่"
- ตัวอัดบันทึกลงฐานข้อมูลตอนกด "หยุดและบันทึก" ถ้าปิดบริการกลางคัน สิ่งที่อัดไว้จะหาย
- Action สูงสุด 500 ต่อแมโคร, รันได้ไม่เกิน 30 นาทีต่อครั้ง (กันวนไม่หยุด)

## ติดตั้งผ่าน GitHub Actions

อัปโหลด ZIP นี้ที่รากของ Repository (Add file → Upload files) และสร้างไฟล์ `.github/workflows/build-apk.yml` (ถ้ายังไม่มี) Workflow จะแตก ZIP จัดโครงสร้าง แล้ว Build APK ดาวน์โหลดจาก Actions → การรันล่าสุด → Artifacts → `MacroFlow-Debug-APK`

Debug APK ถูกเซ็นด้วยคีย์ Debug โดยอัตโนมัติ ติดตั้งบนมือถือได้เลย
